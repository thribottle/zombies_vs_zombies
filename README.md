# 僵尸斗蛐蛐 · PvZ 魅惑僵尸 vs 僵尸 模拟器

用离散时间步模拟《植物大战僵尸》里魅惑僵尸与普通僵尸的群战。
无依赖、无需服务器、手机适配。


## 使用

1. 双击 `zvz.html`（或放到任意静态网站目录）用浏览器打开
2. 每列点 **+** 添加一行，下拉框选僵尸种类、填写数量
3. 在「模拟轮数」里填轮数，点「开始模拟」
4. 模拟完成后显示结果

## 规则

- 每个 tick = 0.1 秒；双方**开局即贴身扎堆**，没有入场行走
- 近战按**栈位优先**选目标，投石车/冰车按距离选最近
- 啃食 100 / 0.5 秒；进入攻击距离就站定输出；冰车碾压阶段不停车
- 铁门、梯子的防具对啃食无效（直接打本体）；路障/铁桶/头盔会被啃掉，先扣防具再扣本体
- 巨人：锤击 1800 / 约 3 秒，血量 ≤50% 时把小鬼放在脚下
- 小丑：随机引信 10~30 秒，爆炸秒杀半径 1.5 格内敌方并自毁（未加入早爆丑、晚爆丑概念）
- 读报：报纸被打掉后进入二阶段，移速 ×2
- 舞王：定时补满 4 只伴舞，魅惑方的伴舞同样为己方作战
- 投石车：篮球 75 伤害、20 颗、约 3 秒一颗，扔完转为移动碾压
- 随机性：个体出手相位、每 tick 出手顺序、小丑引信

## 数值依据

伤害沿用 PvZ 内部单位：**1 颗豌豆 = 20 伤害**。

- 血量：普通 270、路障 640（370+270）、铁桶 1100（830+270）、铁门 1370（1100+270）、
  橄榄球 1670（1400+270）、巨人 3000、红眼 6000、冰车 1350、小丑 490、撑杆/舞王 500……
  取自 PvZ Wiki 与社区反编译资料
- 啃食 **100 / 0.5s**：坚果墙 4000 血约 20 秒被单只普通僵尸啃穿
- 巨人锤击 **1800**：等于樱桃炸弹伤害；两锤可击杀另一只巨人（2×1800 ≥ 3000）
- 冰车碾压做成"接触秒杀"
- 个别数值存在不同版本（如读报本体 200/270、小鬼 300/270），可直接修改 `zvz.html` 中的 `ZOMBIE_ROWS` 表
